# Security Policy / 安全策略

If you find a security issue, please open a private advisory or contact the maintainers.

Do not publish exploit details before maintainers have had a chance to respond.

## Scope

This project stores templates and starter scripts. The most likely risks are:

- accidental secret leakage,
- unsafe example prompts,
- destructive automation defaults,
- external action without approval.

## Default Safety Model

- No real credentials in the repository.
- No destructive external actions by default.
- Human approval required for credentials, deletion, external posting, payments, legal or financial actions.
