# Evolution System / 进化系统

## Purpose

The evolution system turns external mature practices and local lessons into verified upgrades.

It must not become a random idea bucket. Every candidate must pass value screening before becoming a task.

## Candidate Types

- External pattern: a method, paper, tool, or architecture from outside.
- Local lesson: a repeated failure or successful fix observed in the team.
- Quality pattern: a QA rule that should become a reusable gate.
- Persona/process pattern: a communication or role behavior improvement.

## Promotion Gate

A candidate can become a task only if it has:

- Problem solved.
- Expected value.
- Cost and risk.
- Owner.
- Next action.
- Acceptance criteria.
- Evidence plan.

## 中文

进化系统的价值不是“每天刷很多候选”，而是让系统越来越会工作。

候选进入主控前必须先筛选：

- 是否服务当前主线？
- 是否能提高效率、质量、协作或体验？
- 是否可以验证？
- 是否值得占用团队资源？

高价值候选由产品角色结构化，再进入任务系统；低价值候选归档，不污染主线。
