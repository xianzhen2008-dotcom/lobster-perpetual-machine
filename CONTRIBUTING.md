# Contributing / 贡献指南

Contributions are welcome.

## Good Contributions

- Clearer operating protocols.
- Better starter templates.
- Safer privacy defaults.
- Better examples for real project loops.
- Integrations with agent runtimes, task systems, or chat systems.

## Principles

- Do not add private data.
- Keep examples generic.
- Prefer evidence-based workflows over vague agent enthusiasm.
- Keep prompts readable.
- Make the system easier for new users to start.

## 中文

欢迎贡献：

- 更清晰的运行协议。
- 更好的新人启动模板。
- 更安全的隐私默认值。
- 更真实的项目闭环案例。
- 与不同 agent runtime、任务系统、聊天系统的集成。

请不要提交私人数据、密钥、真实业务记录或不可公开的聊天内容。
